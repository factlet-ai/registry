# Factlet Protocol — registry

Community-contributed example factbooks for the [Factlet Protocol](https://factlet.ai). Real artifacts that implementers and protocol users can read, fork, and learn from.

## Browse

Examples are organized under `examples/<domain>/`:

- *(examples coming soon — first batch: payments, ML pipeline, frontend conventions, regulated industry)*

Each example includes a `factbook.yaml` conforming to the v0.1 schema and a `README.md` explaining what the example illustrates.

## Contribute an example

See [CONTRIBUTING.md](CONTRIBUTING.md). What's expected:

- Schema-valid against the published v0.1 spec
- No secrets, no PII, no proprietary content
- Synthetic + sanitized examples preferred over real internal data
- README explains what the example teaches
